# 🧭 SZTU-Trip-Planner Backend

Golang + Gin 后端服务
提供注册登录、行程管理、路线规划等 RESTful API

## 🚀 快速启动

### 准备环境
- [Docker](https://www.docker.com/get-started/)

### 运行

```bash
docker compose up -d
```
